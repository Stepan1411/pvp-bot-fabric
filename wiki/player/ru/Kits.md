# Комплекты

Сохраняйте и загружайте пресеты оборудования для ботов. Наборы сохраняются глобально в`config/pvpbot/kits.json`.

## Создание комплектов

1. Оснастите своего персонажа нужными предметами.
2. Запустите команду создания:

```
/pvpbot kit create-kit warrior
/pvpbot kit create-kit archer
```

Наборы сохраняют все 41 слот инвентаря (панель быстрого доступа, основной инвентарь, броня, дополнительная рука) как данные NBT.

## Применение наборов

### Одному боту или игроку
```
/pvpbot kit give-kit Bot1 warrior
```

### Ботам в радиусе действия
Раздайте комплект всем ботам в радиусе (по умолчанию: 10):
```
/pvpbot kit give-kit-near warrior 15
```

### Случайный взвешенный комплект для ботов в радиусе действия
Выдайте случайный комплект в зависимости от веса ботам в радиусе:
```
/pvpbot kit give-kit-near-random 15 warrior 60% archer 30% mage 10%
```

Каждый бот в радиусе 15 блоков получает по одному комплекту в зависимости от распределения веса.

### Для всей фракции
```
/pvpbot faction kit give-kit Red warrior
```

### Случайный вес комплекта для фракции
```
/pvpbot faction kit give-kit-random Red warrior 60% archer 30% mage 10%
```

## Управление комплектами
```
/pvpbot kit kits                  # List all kits
/pvpbot kit delete-kit warrior    # Delete a kit
```

## Примечания

- Наборы полностью очищают инвентарь цели перед применением.
- `give-kit-near`и`give-kit-near-random`требуется игрок-исполнитель
- `give-kit-random`и`give-kit-near-random`работа с консоли или плеера
- Названия наборов не чувствительны к регистру.
- Наборы являются глобальными (общими для всех миров)
- Поддерживаемые предметы включают в себя любой предмет Minecraft с полными данными NBT (чары, урон и т. д.).
