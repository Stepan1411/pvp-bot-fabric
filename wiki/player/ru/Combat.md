# Боевая система

Боевой ИИ автоматически управляет выбором цели, переключением оружия и тактическими решениями.

## Режимы оружия

Боты автоматически выбирают лучший режим оружия в зависимости от расстояния и доступных предметов:

| Режим | Оружие | Диапазон | Условия |
|------|--------|-------|------------|
| БЛИЖНЯЯ | Меч/Топор |`melee-range`(по умолчанию 3,5) | Режим по умолчанию |
| ДИАПАЗОН | Лук/Арбалет |`ranged-min-range` - `ranged-optimal-range`| Требуются стрелки |
| МЕЙС | Мейс |`mace-range`(по умолчанию 6.0) |`mace`настройка включена |
| КОПЬЕ | Копье |`spear-range` / `spear-charge-range` | `spear`настройка включена |
| КРИСТАЛЛ | Кристалл ПВП | 2,5–8,0 | См. [Взрывной бой](ExplosiveCombat) |
| ЯКОРЬ | Якорь ПВП | 2,0 – 8,0 | См. [Взрывной бой](ExplosiveCombat) |

## Выбор цели

Целевой приоритет (оценивается на каждом такте):

1. **Принудительная цель** — устанавливается через`/pvpbot bot-management attack`
2. **Месть** — автоматически атакует последнего нанесшего урон (тайм-аут 30 секунд).
3. **Враги фракции** — враждебные члены фракции (если фракции включены)
4. **Автонаведение** — ближайший действительный враг в радиусе действия.

Допустимыми целями могут быть игроки, враждебные мобы и другие боты (настраиваются в настройках).

## Боевые особенности

### Критические удары
Боты прыгают перед атакой, чтобы нанести критические удары, когда`criticals`включен.

### Управление щитом
- Предсказывает атаки противника на основе направления спринта и расстояния.
- Превентивно поднимает щит, используя систему прогнозирования.
- Низкое здоровье вызывает удержание щита.
- Щит мерцает для непредсказуемости

### Разрушение щита
Когда враг блокирует удар, боты ломают его топором-щитом с настраиваемым шансом.

### Прогнозирование атаки противника
Отслеживает изменения позиции противника, состояние спринта и расстояние, чтобы предсказать время атаки для поднятия щита.

### Логика отступления
Когда здоровье падает ниже`retreat-health-percent`:
- Поднимает щит и уходит
- Использует лечебные зелья, если таковые имеются.
- Размещает паутину, чтобы замедлить преследование.
- Ест пищу для регенерации

### Булава защиты
Обнаруживает врагов с помощью булавы (в воздухе, при падении) и упреждающе поднимает щит — компенсирует ванильный баг со щитом.

### Размещение паутины
Боты могут накладывать паутину на цели, чтобы обездвижить их (используются предметы из инвентаря).

## Справочник по настройкам

| Настройка | По умолчанию | Описание |
|---------|---------|-------------|
| боевой | правда | Включить/отключить бой полностью |
| месть | правда | Автоматически задействовать последнего нападавшего |
| автоматический таргетинг | ложный | Автоматическое обнаружение ближайшей цели |
| целевые игроки | правда | Ориентируйтесь на реальных игроков |
| мишени-мобы | ложный | Нацельтесь на враждебных мобов |
| таргет-боты | ложный | Нацеливайтесь на других ботов |
| критика | правда | Используйте критические удары в прыжке |
| время восстановления атаки | 10 | Тики между атаками |
| ближний бой | 3,5 | Дальность атаки в ближнем бою |
| упустить шанс | 0% | Шанс пропустить атаки |
| ошибка-случайность | 0% | Шанс ошибиться при прицеливании |
| атака-непобедимая | ложный | Атакуйте творческих/зрительных игроков |
| скорость прицеливания | 60 | Скорость вращения (град/сек) |
| расстояние обзора | 64 | Максимальная дальность обнаружения цели |
