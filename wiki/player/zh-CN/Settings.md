＃ 设置

所有设置均按世界保存在`config/pvpbot/worlds/<worldname>/settings.json`。

## 查看和更改

```
/pvpbot settings                # List all settings
/pvpbot settings combat         # View a single setting
/pvpbot settings combat false   # Change a setting
```
